## Getting Started

Install dependencies: 

```bash
npm i
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Testing

Try with commands such as:
```bash
npm run test
```

```bash
npm run test:watch
```
